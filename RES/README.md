# OnePlus 9 Pro overlays

This directory intentionally contains no OnePlus 13 hardware files.

Add only fixes that have been verified on the OnePlus 9 Pro, using a partition-mirrored path such as `RES/vendor/etc/...` or `RES/product/etc/...`.

The porter copies these files after assembling the ROM and then regenerates fs_config/file_contexts metadata.
